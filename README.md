A program that writes one short original poem about stopping — knowing when to rest, set the work down, and let the quiet in — to `$MAKEFUN_OUTPUT_DIR/entry.txt`. The poem is a fixed string, so every run produces byte-identical output.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```
